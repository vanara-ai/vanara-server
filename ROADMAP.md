# Vanara.ai Roadmap

Vanara.ai is an open-source, MIT-licensed AI resume optimization tool. It helps job seekers optimize their resumes to pass Applicant Tracking System (ATS) screening, at no cost, using a bring-your-own-key model so user data is never stored.

This roadmap lists the features we are committed to building next. Dates are targets, not guarantees.

## Planned features

### Q3 2026 — Transparency & Explainability Card
A per-run explanation card that shows the user exactly what the AI changed and why, including which job-description requirements drove each change and a confidence score. Builds on the existing anti-hallucination guardrails.

### Q4 2026 — Plain-Language / Reading-Level Mode
An option to constrain AI rewriting to a controlled reading level while preserving the candidate's authentic voice. Aimed at non-native English speakers and workers without postsecondary education.

### Q1 2027 — Veteran MOS-to-Civilian Skills Translator
Uses the public-domain U.S. Department of Defense COOL Military Occupational Specialty Crosswalk to convert MOS codes, AFSCs, and Navy ratings into civilian skill statements and job-family matches. Targets the gap veterans face translating military experience into civilian resumes.

## Ongoing
- Continued multi-LLM provider support
- Accessibility hardening toward Section 508 / WCAG 2.1 AA
- Ongoing open-source maintenance: issue triage, PR review, dependency and security updates

## Future direction (no firm dates)
- A public benchmark dataset for evaluating resume-rewriting quality
- A reference deployment guide for U.S. workforce-development organizations
